# Native pointer source screen lane

2 October 2026. Bounded owner files: `apps/controller-native/src/PointerLab.tsx` and this record. Root retains App navigation, packages, aliases, exports, release gates and hardware qualification. Approved design: `2026-10-02-pointer-provider.md`; existing native theme/Button supplies monochrome presentation.

Default `PointerLab({onClose})` renders a labelled local lab, explicit pairing disclosure, central measured touch pad, directional controls, held-contact control, readable status and Stop/Close. The source always initiates native RTC and creates its own reliable/disposable channels through the actual RTCPeerConnection/RTCSessionDescription producer adapter. An expo-crypto 16-byte random epoch binds manual offer/answer parsing and a distinct `native:${epoch}` monotonic clock. Pairing details explicitly distinguish code possession from endpoint authentication. Clipboard transfer is real; failed clipboard access leaves selectable offer text for manual copying. Receiver resource selection stays with the receiver owner.

The shared provider is created before negotiation and ticked by an owned 10ms interval. Input becomes accessible only through `provider.driver()` after both open channels and actual selection of Position and Contact. RN changedTouches feed validated numeric identifiers and locationX/locationY into begin/move/end; measured onLayout width/height makes resize reanchor in the shared driver without an absolute target jump. Touch cancellation and responder termination release. Four labelled Button controls nudge the same driver; contact uses Pressable press-in/press-out and an explicit accessibility activate action to toggle the same contact state.

Stop retires the generation, releases/stops the provider, clears its interval and peer listener, closes the peer and clears pairing/input state. AppState inactive/background, unmount, Close, peer failure, API/provider failure and failed negotiation retire the same session. Fresh connection creation is explicit. All async offer/answer/copy continuations and peer/provider callbacks check current generation, current session and mounted state. Returning to foreground does not reconnect automatically. Raw diagnostics, numeric transport measurements and game InputFrame are absent from this control surface.
