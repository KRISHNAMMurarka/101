# General resource binding implementation plan

Base `37edebc`, 2 October 2026. Execute inline under existing authorization. This expands Task 2 of the [transport plan](2026-10-02-device-transport-bridge.md), with one root integration owner and one disjoint remote-clock worker. No physical or global persistent identity claim.

Outcome: independent typed pointer/contact and temperature flow through negotiated general resources into host-authorized embedded sinks; stale, cross-peer, malformed, overloaded and uncertain-clock traffic cannot mutate those sinks.

## Frozen interfaces and ownership

- Root owns `packages/device-web/{package.json,src/{wire.ts,wire.test.ts,binding.ts,binding.test.ts,index.ts}}`, runtime effective-limit API/test, package aliases/lockfile/facade, first example and central evidence.
- Remote-clock worker owns only `packages/device-model/src/remote-clock{,.test}.ts` and its bounded plan; root integrates exports. It exposes `RemoteClockMap({localClockId,remoteClockId,maxRttMs,maxUncertaintyMs,maxDriftPpm,maxAgeMs})`, `observe({localSentAt,remoteReceivedAt,remoteSentAt,localReceivedAt}):boolean`, `translate(remoteAt,localNow)` returning immutable earliest/latest/uncertainty/IDs, and `reset()`. Full M08 lineage/quality evolution stays open.
- `WirePacket = WireControl | WireValue`, closed connect/1 vocabulary in the revised spec. `decodePacket(data:string|ArrayBuffer,lane:'reliable'|'disposable')` returns `{packet,codec}` or undefined; `encodePacket(packet:unknown,codec='json/1')` returns string/ArrayBuffer or throws. JSON controls always reliable; samples disposable; events reliable. Epoch exactly 32 lowercase hex chars, slots 1..128, positive uint32 sequence, finite nonnegative times; events require decimal safe positive operation IDs and a finite deadline after capture. Describe codecs unique subset of json/1, normalized-pointer/1 and must include json/1. Unknown fields/versions/types/codecs reject. UTF-8 ceiling 66 KiB describe, 4 KiB other messages; descriptor parser owns its independent 64 KiB/depth/count limits. Encode checks inert own data properties before JSON serialization; no getter evaluation.
- Compact pointer layout is the 48-byte profile in the spec; only x/y normalized samples qualify. Receiver checks negotiated codec and exact declared schema before applying decoded values.
- Structural `ResourcePeer` exposes send, onData, onStateChange, isOpen and readonly state. Constructor captures the concrete object. No public receive(peerId,...) or packet authority fields. Fake peers invoke their own captured listener, so cross-peer/session injection cannot address another object's registration.
- `RemoteResourceReceiver({peer,runtime,epoch,principalId,applicationId,sessionId,clockId,now,onStatus?})`: listens for an immutable matching-epoch description; `description()` returns it; `approve({capability,sink,sinkDevice,sinkCapability,grant,codec?,leaseMs?})` returns slot or undefined. Receiver allocates slots monotonically, source handle privately, sends bind and accepts exact ready limits, then starts the embedded route. `Connection.limits()` returns effective maxHz/maxAgeMs/expiresAt only while active; any mismatch releases and rejects before publish. `tick()` flushes/renews active leases, runs bounded clock probes and expires lost freshness; `stop()` releases every source/route/listener and clears clock. No automatic authority renewal beyond grant expiry.
- `RemoteResourcePublisher({peer,device,epoch,clockId,now,available,onStatus?})`: `start()` sends parsed description; owner-supplied available(capability) proves actual provider readiness; binds require descriptor/schema/codec/delivery compatibility and requested limits inside actual provider policy. `publish(capability,value,{capturedAt?,deadline?})` validates declared type and sends only bound slots. Latest state retains at most one replacement per slot when unavailable admission; reliable send rejection stops the slot visibly and sends stop when possible. Sender owns sequences and operation IDs, which never come from caller packets. `tick()` flushes latest under maxHz and expires held state; `stop()` sends stops and detaches listeners. Source readiness removal stops affected slots.
- Clock probes: one outstanding request per receiver, positive ID increasing; response must match exact outstanding ID/sentAt and shared epoch, with both remote timestamps. At most one probe per 1000 ms, outstanding expires after 200 ms; receiver rejects capture until synchronized and bounded uncertainty. Publish uses translated earliest capture, rejects an interval entirely after receipt or age beyond negotiated maxAge; the capture interval's upper bound is clipped at receipt by packet causality. Requiring its untrimmed upper bound <= receipt would incorrectly reject valid zero-delay captures after drift expansion. Event deadline uses earliest expiry and cannot exceed earliestCapture + maxAge. Raw remote capture, remote/local clock IDs, receipt, upper capture bound and uncertainty remain provenance. Unsolicited/duplicate probes do not grant clock authority.
- Epoch/identity/options validation precedes subscriptions. Stop is terminal; fresh transport generation requires a new bridge with fresh trusted epoch and new approval. Peer disconnected/failed releases locally immediately. Invalid/stale packets never refresh deadman. Lost reliable contact is released by deadman/lease regardless of remote stop delivery.

## Decisions

A shared trusted enrollment epoch keeps the first transport bridge independent of global identity/coordinator work while making packet-selected epochs powerless. The host still has to authenticate/enroll the actual peer before constructing this bridge; a local unauthenticated loopback is explicitly only a harness. Registration handles remain in embedded host memory. Exposing effective route limits is smaller than introducing a second authorization engine; mismatch fails safely rather than advertising more capacity than the host permits.

## Execution record

Owner approval also enters the runtime as immutable narrowing constraints after independent review reproduced queued/asynchronous effects beyond approval expiry. It never expands host authorization. Reliable cadence queues have 64 entries; latest keeps one. Producer/receiver timers remain caller-owned, with stop terminal. Initial state notifications are synchronous in production and faithful fixtures; returned subscriptions are detached even when they cause stop during construction.

All exact source gates and two real browser typed-route cases pass; [QA](../../platform/RESOURCE-BINDING-QA-2026-10-02.md) records counts, fingerprints, preserved failures and scope. Complete authenticated endpoint enrollment, relative provider, UI/native and physical acceptance are subsequent bounded tasks.
