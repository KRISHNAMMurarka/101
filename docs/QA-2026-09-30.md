# Local continuation QA — 30 September 2026

This receipt covers the tree committed with this file. All work stayed on this computer. No remote
CI, push, preview, deployment, signing, or distribution was performed. Release acceptance remains

## Changes checked

- Pinned vinext 1.0.0-beta.5. A production `HEAD` request for
  `/mediapipe/wasm/vision_wasm_internal.wasm` now returns `application/wasm`; beta.2 returned
  `application/octet-stream` and forced a streaming-compile fallback.
- Added Playwright as a development dependency and committed repeatable production-browser scripts:
  `qa:layout`, `qa:keyboard`, `qa:growth`, `qa:offline`, and `qa:engines`. Run `npm run build` first;
  each script starts its own local production server. Playwright's Chromium, WebKit, and Firefox
  browser binaries must be installed once with `npx playwright install chromium webkit firefox`.
- The ten-game phone library now keeps all ten cards mounted, so held Tab can reach every game.
  The previous build mounted four and a held Tab jumped from those cards to the footer.
- The pairing dialog returns focus to its trigger in WebKit after Escape. Safari does not put
  pointer-clicked buttons in `document.activeElement`, so restoring that element lost focus.
- Updated vulnerable transitive `brace-expansion` lockfile entries. The production dependency audit
  has no unreviewed advisory; its four existing build-tooling exceptions remain in force.
- Made two existing unit tests independent of scheduler delays: pairing backoff uses a long enough
  observation window for the full suite, and native speaker sequencing tests use a fixed clock.
  The separate 120 ms speaker deadline tests still drive time explicitly. Before these changes,
  the full suite failed once at each of those assertions while each affected file passed alone.
