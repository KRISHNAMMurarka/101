# Explicit units and conversions, 2 October 2026

M06 is implemented in the containing commit from base `bba4e7e`. This is a
local software contract for declared numeric measurements, with a real
authorized telemetry caller and a clean installed SDK consumer. It does not
establish calibration, physical metrology, spatial frame conversion, general
processor qualification or a supported device/runtime release row.

`parseUnitToken()` validates the opt-in conversion spelling. Descriptor schema
1 retains its original bounded string acceptance and exact unit matching, as
required by [C05's compatibility rule](RELEASE-CONTRACT.md#public-names-and-compatibility).
A malformed legacy unit remains inert descriptor data and cannot enter the
conversion API. The converter supports scalar/vector inputs with identical
shape, components and frame. Known affine maps cover `Cel`/`K`, `m`/`cm`/`mm`,
`rad`/`deg`, `s`/`ms`, `kg`/`g`, and `By`/`KiBy`. `1` and unknown valid tokens
allow identity only. Cross-dimension, unknown-pair, frame, range, shape,
precision and budget mismatches fail before publication. No route inserts a
converter or silently normalizes a value.

The converter copies exact inert options once, validates complete source and
target ranges, and requires an explicit decimal precision and absolute error
budget. The bound includes half the declared source resolution after scaling,
half the decimal step and a conservative floating-point margin. A target
resolution cannot advertise finer detail than those steps. Immutable metadata
records scale, offset, precision and bound. These are numeric representation
bounds, not an assertion about sensor error. Input and rounded output are
validated through the existing immutable value parser.

The version 2 [telemetry batch caller](../../examples/device-pipelines/telemetry-batch.ts)
accepts an explicitly labeled `residentKiBy` batch, converts it to declared
`By` before calling `runtime.publish`, and carries the conversion map as
observation provenance. The sink receives 64.5 KiBy as 66048 By through an
authorized route; malformed, oversized and nonfinite input has no further
effect, and stop clears owned telemetry and provenance. Normal byte
publication and version 1 migration remain separate paths.
