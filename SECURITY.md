# Security policy

101 is early-stage software and has not yet published a stable security-support window.

Please report suspected vulnerabilities privately to the repository maintainers rather than opening a public issue. Include affected version, reproduction steps, impact, and a minimal proof of concept. Remove tokens, private device data, recordings, and live pairing payloads.

Public issues are appropriate for non-sensitive hardening ideas and ordinary bugs.

Maintainers use the [security incident and update procedures](docs/platform/SECURITY-MAINTENANCE.md)
for scoped intake, containment, fix validation and update preparation. The private
reporting destination and live update channel remain unconfigured. The owner has
authorized the active 101 integration controller to own triage and approve fixes
within the existing local scope; this supplies no live contact or support promise.
